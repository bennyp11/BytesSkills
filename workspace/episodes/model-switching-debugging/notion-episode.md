# Model switching is a great way to debug

Notion: https://app.notion.com/p/3f44c5d037138189bd3cfdeea45199ea

## Classification
Standalone episode, separate from the 100K in 90 Days challenge.
Format: Troll. Audience: software engineers. Engagement: rage + comment. Delivery: straight-faced.
## Selected premise
Model switching is a great way to debug.
The narrator sincerely recommends switching AI models or buying another subscription instead of improving the same vague prompt, inspecting the error, or providing useful context.
## Initial hook direction
> Unpopular opinion, but model switching is a great way to debug.
This is the first direction to develop, not a finalized or winning opener.
## Why the bit works
Software engineers recognize the temptation to assume a different model will understand an underspecified request. The deliberate overstatement treats changing providers as a complete debugging method.
## Internal truth note
A different model can genuinely provide a useful second opinion. The joke targets repeated switching without examining the bug or clarifying the request, not all use of multiple models.
## Development direction
Keep the performance committed and matter-of-fact. Escalate the logic of trying another model instead of diagnosing the issue. A sincere-sounding request for audience advice should arise from the premise and invite corrections or model recommendations.
