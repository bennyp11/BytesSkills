# Reaction

Status: draft, awaiting one concrete example and clarification of “shaking”.

An on-camera performance in which the creator progressively reacts to a changing
string (word or phrase) or number. The changing value recontextualizes an on-screen
hook question. The relationship between the question, value and reaction defines
the format; music and visual styling are separate creative choices.

## Planning unit

Use one beat per context state: displayed value, what it means for the question,
intended reaction, and eventual timing. This is a proposed planning structure, not
a requirement to add more beats than a piece needs. Numeric values need not increase;
progressive reactions need not become louder or more intense.

## Still to establish

The user's term “shaking” is preserved without guessing a physical action. We also
need a real question/value sequence, whether the question itself stays fixed,
performance timing and ending. No sample content has been invented as an approved
example. Speech, captions beyond hook text, music, sound effects and animations are
not yet specified. A follow CTA from Reductions is not inherited.
